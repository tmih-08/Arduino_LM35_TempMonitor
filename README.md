\# Dự án Mạng Cảm Biến Giám Sát Nhiệt Độ LM35



\## 📝 Mô tả

Hệ thống sử dụng cảm biến LM35 kết nối với Arduino để giám sát nhiệt độ đa kênh. Dữ liệu được xử lý và truyền qua Serial dưới định dạng JSON.



\## ✨ Tính năng

\* Đọc giá trị nhiệt độ từ 3 kênh cảm biến (A0, A1, A2).

\* Xuất dữ liệu định dạng JSON chuyên nghiệp.



\## 🛠 Phần cứng cần thiết

| Linh kiện | Số lượng | Ghi chú |

| :--- | :---: | :--- |

| Arduino Uno R3 | 01 | Board mạch chính |

| Cảm biến LM35 | 03 | Cảm biến Analog |
